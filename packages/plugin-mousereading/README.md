# mousereading

## Overview

Displays a blurred text, which can be read by moving mouse.

## Loading

### In browser

```js
<script src="https://unpkg.com/@jspsych-contrib/plugin-mousereading@1.0.0"></script>
```

### Via NPM

```
npm install @jspsych-contrib/plugin-mousereading
```

```js
import jsPsychMousereading from '@jspsych-contrib/plugin-mousereading';
```

## Compatibility

jsPsych 8.0.0

See [documentation](https://github.com/jspsych/jspsych-contrib/blob/main/packages/plugin-mousereading/docs/jspsych-mousereading.md)
